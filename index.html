Design choices

  • Keep raw data untouched. Every file lands in S3 as received, so any table can be rebuilt after a bug fix.
  • Three warehouse layers. Staging cleans types and duplicates, the core model holds the business entities, and marts answer one team's questions each.
  • Batch and streaming side by side. Finance needs a correct daily number. Operations needs a view that is minutes old. They share the same core model.
  • Checks are part of the pipeline. A failed check stops the load and sends an alert. See Quality and monitoring.

Harborlight Media is a fictional company. All figures are illustrative design targets, not measurements from a real system.
