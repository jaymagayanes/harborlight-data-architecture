Ingestion

Four kinds of source, each loaded in the way that suits it.

Rules every job follows

  • Idempotent. Running a job twice gives the same result as running it once.
  • Incremental by default. Full reloads are for backfills only.
  • Fail loudly. A job that cannot finish cleanly raises an alert and does not write partial data.

Example: rate-limit-safe API pull

def fetch_all(session, url, params, max_tries=5):
    page, rows = 1, []
    while True:
        for attempt in range(max_tries):
            r = session.get(url, params={**params, "page": page}, timeout=30)
            if r.status_code == 429:
                time.sleep(2 ** attempt)   # back off, then retry
                continue
            r.raise_for_status()
            break
        else:
            raise RuntimeError(f"gave up on page {page}")
        data = r.json()["data"]
        if not data:
            return rows
        rows += data
        page += 1
